# Operations Index

Map of where every piece of the Rogue Night Digital Health Check pipeline lives. Use this as the canonical lookup when "where do I find X?" comes up.

---

## The pipeline at a glance

```
Customer journey                         Where it lives
─────────────────────────────────────────────────────────────────────────
1. Discovery (landing page)              public/index.html (Hostinger)
2. Decide to buy                         Tally form (https://tally.so/r/xX4YaG)
3. Submit questionnaire (5-7 min)        Tally form → Airtable Responses
4. Land on thank-you page                public/thank-you/index.html (Hostinger)
5. Pay Now                               Stripe Payment Link (pay.roguenight.com.au)
   ├─ Card payment                       Stripe Checkout (Stripe-hosted)
   └─ Redirect to confirmation           public/confirmation/index.html (Hostinger)
6. Pay Later                             /api/pay-later (Cloudflare Worker)
   └─ Stripe Invoice email               Stripe Invoicing (Hosted Invoice Page)
7. Lois drafts report                    Hyperagent: Lois agent + DHC Report Writer skill
8. Linh reviews and approves draft       Hyperagent chat with Lois
9. Report PDF generated                  Lois (via WeasyPrint in skill scripts)
10. Email sent to customer               Hostinger webmail (manual copy-paste by Linh)
11. Recommendations written to Airtable  Hyperagent: Lois calls write_back.py
12. stack.md additions proposed          Hyperagent: Stack.md Maintainer skill
```

## Source of truth, by category

### Website
- **Build scripts:** `src/build_*.py` (this repo) — canonical
- **Built output:** `public/` (this repo) — generated by `src/build_all.py`, uploaded to Hostinger
- **Brand kit:** `docs/BRAND-KIT.md` (this repo) — canonical
- **Voice rules:** `docs/operations/VOICE-RULES.md` (this repo) — canonical
- **Deployment instructions:** `docs/DEPLOYMENT-GUIDE.md` + `docs/PAYMENT-FLOW.md` (this repo) — canonical

### Payment flow
- **Thank-you page logic:** `src/build_thank_you.py` (this repo) — canonical
- **Worker code:** `cloudflare-worker/worker-pay-later.js` (this repo) — canonical
- **Stripe Payment Link config:** Stripe Dashboard → Payment Links — canonical (linked from this repo's PAYMENT-FLOW.md)
- **Tally form spec:** Tally dashboard at `https://tally.so/r/xX4YaG` — canonical. Documented in `docs/operations/QUESTIONNAIRE.md` and `docs/operations/AIRTABLE-SCHEMA.md` (this repo) for reference.

### Agents and skills
- **Lois system prompt:** `agents/lois/system-prompt.md` (this repo) — canonical
- **Lois identity, tools, integrations:** `agents/lois/README.md` (this repo) — canonical
- **DHC Report Writer skill (methodology + scripts):** `agents/dhc-report-writer/` (this repo) — canonical
- **Stack.md Maintainer skill:** `agents/stack-md-maintainer/` (this repo) — canonical
- **Hyperagent runtime copies:** mirror what's here; if drift occurs, this repo wins (push via `UpdateSkillAndScripts`)

### Tool catalogue
- **`catalogue/stack.md`** (this repo) — canonical
- **Airtable Tools table** (`appCLdTCbJ5zGe9fo/tblNDMmrH2zS8JR5K`) — runtime mirror. Synced by the Stack.md Maintainer skill.

### Data
- **Airtable Responses, Recommendations, Reports tables** — canonical for client data (one row per submission)
- **Per-client report PDFs** — generated by Lois on demand. Stored as Airtable attachments on `Reports.Report PDF` and (when needed) published as public URLs via `PublishFilePublicly`.
- **`catalogue/stack.md`** — canonical for the vetted tool catalogue. Refresh quarterly.

### Operations documentation
- **Airtable schema:** `docs/operations/AIRTABLE-SCHEMA.md` (this repo) — canonical, mirrors the live base
- **Questionnaire spec:** `docs/operations/QUESTIONNAIRE.md` (this repo) — canonical, mirrors the live Tally form
- **Stack.md audit findings:** `docs/operations/STACK-AUDIT-*.md` (this repo) — dated snapshots
- **Voice rules:** `docs/operations/VOICE-RULES.md` (this repo) — canonical

### Secrets and credentials
- **Stripe API keys** — Stripe Dashboard → Developers → API keys. Worker secrets store the active key.
- **Airtable Personal Access Token** — Hyperagent skill credentials store. Generated at `airtable.com/create/tokens`, scoped to the DHC base only.
- **Cloudflare API token** (if used for `wrangler` CLI) — Cloudflare dashboard → API Tokens. Local-only, not in this repo.
- **Hostinger SSH / FTP credentials** — Hostinger hPanel. Local-only.

**Never in this repo:** any of the above.
